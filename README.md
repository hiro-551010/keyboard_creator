# Keyboard Creator

ブラウザ上で分割キーボードのプレート、トップケース、ボトムケースを設計・3D表示・エクスポートできるWebアプリケーション

## 機能

- **レイアウトエディタ**: 左右のハーフを個別に編集できるグリッドベースのエディタ
- **3Dビューアー**: Three.jsによるリアルタイム3Dプレビュー
- **パラメータ調整**: キーサイズ、プレート厚み、ケース設定などを調整可能
- **STLエクスポート**: 3Dプリンタ用のSTL形式でエクスポート

## 技術スタック

- React + TypeScript
- Three.js (3Dレンダリング)
- Vite (ビルドツール)

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 使用方法

1. レイアウトエディタで左右のハーフにキーを配置
2. パラメータパネルで各種設定を調整
3. 3Dビューアーでプレビューを確認
4. エクスポートパネルからSTL形式でダウンロード
