# タスク一覧: ドラッグアンドドロップでキー位置調整機能

## ブランチ名
`feature-drag-and-drop-keys`

## 実装概要
現在のグリッドベースのキー配置を、ドラッグアンドドロップで柔軟に位置調整できるように改善する。

## 実装タスク

### 1. ドラッグアンドドロップ機能の実装
- [ ] KeySlotコンポーネントにドラッグイベントハンドラーを追加
- [ ] ドラッグ開始時の処理（キー情報の保持）
- [ ] ドラッグ中の処理（視覚的フィードバック）
- [ ] ドロップ時の処理（位置更新）

### 2. 位置計算の改善
- [ ] グリッド座標から自由な座標への変換
- [ ] キーの位置をピクセル単位またはmm単位で保存できるように型定義を拡張
- [ ] 既存のグリッドベースの位置との互換性を維持

### 3. UI/UXの改善
- [ ] ドラッグ中のキーの視覚的フィードバック（半透明、影など）
- [ ] ドロップ可能な領域のハイライト
- [ ] スナップ機能（グリッドにスナップするオプション）
- [ ] キーのサイズ変更機能（リサイズハンドル）

### 4. レイアウトエディタの改善
- [ ] グリッド表示のオプション（表示/非表示）
- [ ] ズーム機能（細かい位置調整のため）
- [ ] パン機能（大きなレイアウトの編集のため）

### 5. データ構造の拡張
- [ ] Key型に自由な位置情報を追加（x, y座標）
- [ ] 既存のグリッドベースの位置との変換関数
- [ ] レイアウトの保存/読み込み時の互換性維持

### 6. 3Dビューアーとの連携
- [ ] 自由な位置のキーを3D空間で正しく表示
- [ ] 位置変更時の3Dビューアーの自動更新

### 7. テストと検証
- [ ] ドラッグアンドドロップの動作確認
- [ ] 既存機能との互換性確認
- [ ] パフォーマンステスト

## 技術的な考慮事項
- React DnD または react-beautiful-dnd などのライブラリの検討
- または、ネイティブのHTML5 Drag and Drop APIを使用
- パフォーマンスへの影響を最小限に
- モバイルデバイスでのタッチ操作への対応（将来の拡張）

## 実装の優先順位
1. 基本的なドラッグアンドドロップ機能（タスク1, 2）
2. UI/UXの改善（タスク3）
3. レイアウトエディタの改善（タスク4）
4. データ構造の拡張と3D連携（タスク5, 6）
5. テストと検証（タスク7）
