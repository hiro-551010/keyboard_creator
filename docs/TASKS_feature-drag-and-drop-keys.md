# タスク一覧: ドラッグアンドドロップによるキー位置調整機能

## 概要
現在のグリッドベースの固定位置配置から、ドラッグアンドドロップでキーの位置を自由に調整できる機能を実装する。

## 実装タスク

### 1. ドラッグアンドドロップ機能の基盤実装
- [ ] KeySlotコンポーネントにドラッグイベントハンドラーを追加
- [ ] ドラッグ開始時の処理（dragstart）
- [ ] ドラッグ中の処理（dragover, dragenter）
- [ ] ドロップ時の処理（drop）
- [ ] ドラッグ中の視覚的フィードバック（カーソル変更、ハイライト表示）

### 2. キー位置の柔軟な配置
- [ ] グリッドに縛られない位置指定の実装
- [ ] キーの位置をピクセル単位またはmm単位で保存できるように型定義を拡張
- [ ] KeyPosition型にoffsetX, offsetYなどのオフセット情報を追加（オプション）

### 3. レイアウトエディタのUI改善
- [ ] グリッドエディタをより柔軟な配置に対応
- [ ] ドラッグ可能なキーの視覚的インジケーター
- [ ] ドロップ可能な領域のハイライト表示
- [ ] キーの重なりチェック機能（オプション）

### 4. データ構造の更新
- [ ] KeyboardLayout型の拡張（必要に応じて）
- [ ] キー位置の計算ロジックの更新（keyPositionTo3D関数の修正）
- [ ] 既存のグリッドベースの位置と新しい柔軟な位置の互換性維持

### 5. 3Dビューアーとの連携
- [ ] 柔軟な位置で配置されたキーが3Dビューアーで正しく表示されることを確認
- [ ] プレート生成ロジックが新しい位置情報に対応

### 6. テスト・検証
- [ ] ドラッグアンドドロップの動作確認
- [ ] キー位置の保存・読み込みの確認
- [ ] 3D表示との整合性確認

## 技術的な考慮事項
- React DnDライブラリの使用を検討（react-dnd または react-beautiful-dnd）
- または、ネイティブのHTML5 Drag and Drop APIを使用
- パフォーマンスへの影響を考慮（多数のキーがある場合）
- 既存のグリッドベースの機能との共存

## 実装の優先順位
1. 基本的なドラッグアンドドロップ機能（タスク1）
2. データ構造の更新（タスク4）
3. UI改善（タスク3）
4. 3Dビューアーとの連携確認（タスク5）
5. 高度な機能（重なりチェックなど）（タスク2の一部）
