# タスク一覧: グリッドエディタを方眼紙風の見た目に変更

## ブランチ名
`feature-grid-paper-style`

## 実装概要
現在のグリッドエディタの区切り線を、二次関数のような方眼紙的な見た目に変更する。数学のグラフ用紙のような見た目で、より柔軟な位置調整の視覚的サポートを提供する。

## 実装タスク

### 1. グリッドスタイルの変更
- [x] 現在の均一なグリッド線を、方眼紙風のスタイルに変更
- [x] 細かいグリッド線（5px間隔）と太いグリッド線（20px間隔）を実装
- [x] グリッドの背景色と線の色を調整
- [ ] グリッドの密度を調整可能にする（オプション）

### 2. CSSの実装
- [x] 方眼紙風の背景パターンをCSSで実装
- [x] グラデーションやパターンを使用した視覚効果
- [x] グリッド線のスタイルを調整（透明度、太さなど）

### 3. UI/UXの改善
- [x] 方眼紙風の見た目がキーの配置を妨げないようにする
- [x] 視認性を保ちながら、美しい見た目を実現
- [x] キースロットを半透明にして背景が見えるように調整

### 4. パフォーマンス
- [x] CSSパターンのパフォーマンスへの影響を確認
- [x] 必要に応じて最適化

## 技術的な考慮事項
- CSSの`background-image`と`linear-gradient`を使用して方眼紙風のパターンを実装
- 複数の背景レイヤーを重ねて、細かいグリッドと太いグリッドを表現
- 既存のグリッド機能との互換性を維持
